6) PROBLEM VANDHA (troubleshooting)
-----------------------------------
  "java: command not found" illa "javac is not recognized"
      -> JDK install illa. Install pannunga:
         Windows : winget install Microsoft.OpenJDK.21
         macOS   : brew install openjdk@21
         Ubuntu  : sudo apt install openjdk-21-jdk
         illa    : https://adoptium.net  ->  Temurin 21 (JDK)
      -> Install panna pinne VS Code-a close panni thirumba open pannunga
         (PATH varum).

  "port already in use"
      -> pazhaya server window innum open-a irukku. Adha close pannunga
         (illa Windows la:  taskkill /F /IM java.exe ), apram thirumba start.

  Vera port venum-na:
      Windows : set PORT=9000 && java Server
      Mac/Linux: PORT=9000 java Server
